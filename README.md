# CLANK CITY

A responsive 2D city-building and token district explorer concept for the Clanker ecosystem on Base.

## Prototype gameplay
- Explore and select six demo districts on the interactive 2D map.
- Spend City Credits to upgrade the selected district.
- District levels and city level progress as upgrades are completed.
- Progress is saved locally in the player's browser using local storage.

## Data and chain status
District market caps, volumes, community counts, and token names are illustrative demo data. Live market data, real token contract addresses, wallet connection, and on-chain transactions are not connected yet. City Credits are in-game prototype points only and have no monetary value.

Clank City is an unofficial community concept and is not affiliated with Clanker.

## Deploy to Cloudflare Pages
1. Connect the GitHub repository `musclank/clank-city` to Cloudflare Pages.
2. Framework preset: **None**.
3. Build command: leave empty.
4. Build output directory: repository root (`/`).

The standalone `index.html` includes its CSS and JavaScript, so no build step is required.
