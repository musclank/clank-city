# CLANK CITY

A responsive 2D pixel-style city explorer prototype for the Clanker ecosystem on Base.

## Deploy to Cloudflare Pages
1. Upload `index.html` and `favicon.svg` to the root of this GitHub repository.
2. Connect the repository to Cloudflare Pages.
3. Framework preset: None. Build command: leave empty. Build output directory: `/` (root).

The standalone `index.html` includes its CSS and JavaScript, so no build step is needed. Token stats and contract addresses are illustrative demo data, not live market data. This is an unofficial community concept and is not affiliated with Clanker.
